# TerraVault — Hyderabad Pilot Offer (Phase 1)

**Valid:** June–August 2026 · **Slots:** 3 founding partners · **Region:** Hyderabad & surrounding

---

## The problem

Indian organisations must retain sensitive records under **DPDPA 2023** — with fines up to ₹250 crore for serious breaches. Most teams still rely on on-premise servers (ransomware risk), cloud cold storage (egress surprises), or informal archives (audit failure).

---

## What TerraVault provides

| Capability | Detail |
|------------|--------|
| **Air-gapped storage** | LTO-9 magnetic tape in Tier-4 Hyderabad colocation — physically offline after write |
| **Searchable dashboard** | Metadata index online; clients search by name, date, category — no tape location exposed |
| **15-minute retrieval** | Request online → ops fulfils from tape → secure download link → auto-purge |
| **DPDPA workflows** | Right to Erasure requests, immutable audit log, signed PDF certificates |
| **Tape health** | Fill %, write cycles, proactive re-copy alerts |
