TerraVault

Managed offline archival for regulated Indian enterprises — Phase 1

The Idea

A physical, air-gapped data vault — managed like cloud, secured like a bunker.

Hospitals, pharma, and enterprises must keep records for years under DPDPA 2023. We store their archive on LTO-9 magnetic tape in a Tier-4 facility — permanently offline after write — and give them a web dashboard to search metadata, request files, and prove compliance. Not another cloud drive. A purpose-built compliance archive service.

The Need

  • DPDPA enforcement — retention, safeguards, erasure proof, audit readiness; fines up to ₹250 Cr
  • On-premise risk — ransomware, fire, hardware failure on ageing NAS and servers
  • Cloud cold storage — unpredictable retrieval costs, always-online attack surface, sovereignty concerns
  • No good India-native option — global vault vendors lack DPDPA-first tooling; DIY compliance is expensive

What Must Exist

  • Physical layer — LTO library, tapes, Tier-4 colocation (Hyderabad first), climate-controlled vault
  • Operations — ingest, tape catalogue, 15-min retrieval SLA, technician runbooks, tape health lifecycle
  • Software — client + admin portals, metadata index, job queue, immutable audit log
  • Compliance — SHA-256 verify on every write, signed PDF certificates, Right to Erasure workflow
  • Security boundary — file bytes on tape only; online systems hold metadata and jobs, never permanent content

How It Gets Built

01
Facility & Hardware
Lease rack in Tier-4 colo. Deploy LTO-9 library, drives, ingest workstation. No owned data centre.
02
Ingest Pipeline
Client ships data via SFTP or courier → index + checksum → write tape → read-back verify → shelf.
03
Sentinel Dashboard
Search, retrieval requests, SLA tracking, billing visibility. Admin sees tape location; clients do not.
04
Scale & Trust
Pilot 3 Hyderabad clients → prove SLA and certificates → expand metros, optional multi-site tape mirrors.
